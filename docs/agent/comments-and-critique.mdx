## Comment threads

Use a comment thread when you want to discuss one passage before deciding whether to change it. Comments appear in the gutter and remain anchored to a text range. Open a thread to reply, send feedback, or inspect edits that belong to the discussion.

An unresolved passage has an inline underline and a small message count pill. Click either marker to open the gutter card.

Use **Resolve** when the discussion is complete. Resolving a thread also drops pending edits linked to the thread. Use **Reopen** when the discussion should continue.

When the anchor text is deleted, the detached thread disappears from the gutter. Undoing the deletion restores the text and can restore the thread anchor.

## Proposed fixes in comments

An agent message can include **Approve and propose edit** when the agent has explained a problem without changing the draft. Approving asks the agent to turn the explanation into a reviewable change, so you can inspect the exact wording before accepting it.

Replying to a thread wakes the agent with the thread transcript. The agent can respond to the discussion and group later edits under the same thread.

## Critique passes

Open **Settings**, then **Critique pass**. Built in reviewers include PhD Advisor, Copy Editor, Skeptic, and Fresh Eyes.

<Frame>
  ![The built in critique passes in Settings](/images/critique-pass-menu.png)
</Frame>

A critique pass is useful when you want the whole active draft reviewed from one point of view. For example, the Copy Editor can look for sentence problems, while the Skeptic can look for claims that need more support.

The reviewer reads the active draft and can produce up to six focused findings. Findings arrive as comments, and the reviewer can also propose a fix. You can discuss each finding, accept a linked edit, or resolve the thread. The reviewer name and mascot remain attached to the resulting comments and edits.

Choose **New reviewer** when you need a review that matches your own project or audience. Provide a name, mascot, color, and review prompt that explains what the reviewer should check.
