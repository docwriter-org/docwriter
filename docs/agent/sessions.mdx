---
title: "Sessions"
description: "Return to an earlier conversation or clear the current one."
---

A session contains the conversation between you and the selected provider. Use separate sessions when you want to return to an earlier discussion or start work without the instructions and assumptions from the current conversation. Switching sessions does not replace your workspace files.

## Open an earlier session

Open **Settings**, then **Sessions**. Search the saved sessions and choose one to restore its provider, model, and conversation when possible. You can then continue the earlier discussion with its saved context.

A provider session may expire or disappear from the provider. If DocWriter cannot resume it, start a new session and send the needed context again.

## Start a new session

Choose **New session** in the agent dock when you want the next request to start without the current conversation or pending agent work. For example, start a new session after finishing one chapter when you do not want its detailed discussion to shape work on another chapter.

A new session clears:

- The provider conversation and activity log.
- Queued work and active questions or plans.
- Pending edit proposals.
- Session cost and recent feedback actions.
- Temporary agent files under `.docwriter/agent/scratch/`.

Your workspace files, comments, rules, references, hooks, reviewers, installed skills, appearance, and agent behavior settings remain.

Accept or copy any proposal you need before starting a new session. Pending proposals are removed as part of the reset.
