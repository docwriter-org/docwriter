## Read a proposal

A proposal is tracked changes in the draft: green text is an addition and red struck text is a removal, word by word. A line the agent adds or removes is marked whole. Every proposal belongs to a comment thread, and the thread's card in the gutter lists each changed paragraph as before and after.

Hover a card to flash the matching text. Click a highlighted passage or its pill to open the thread.

## Accept or reject

Open a thread's card and use **Accept** or **Reject**. Accept keeps the added text and removes the struck text. Reject puts the original back. Both close the thread; reopen it from the gutter if you want to continue the discussion.

**Accept all** accepts every proposal in the current tab. **Reject all** removes every proposal in the current tab. Neither action affects another tab.

<Frame>
  ![The Accept all and Reject all controls above pending suggestions](/images/agent-accept-reject-all.png)
</Frame>

Reply on the thread when the agent should revise the proposal. The agent's new proposal replaces the old one on the same thread. Dismiss the thread when you are done with the discussion; dismissing removes a proposal you did not accept.

A passage has one thread. Feedback you give on a passage that already has a thread becomes a reply on that thread, and the agent is told to use it.

Your own typing is never part of a proposal. Text you type inside a proposal stays when the proposal is rejected. If you edit the file outside DocWriter through a passage under proposal, that proposal goes with the text and its thread card says the passage is no longer in the document.

## Copy proposed text

Use **Copy proposed text** on a thread card. You can also select added text in the editor and copy it normally; it pastes as plain text.

## AI provenance

Accepted agent text receives an AI provenance mark so you can find wording that came from an accepted proposal. Use **Highlight AI-written text** to show or hide the marks. Typing your own replacement inside a marked span removes the mark from the text you add.

## Undo

Accept and reject actions use the same undo history as your typing. Press **Command or Control and Z** to undo the latest action, including an accidental accept or reject.

After you accept a paragraph edit, the changed range briefly flashes so you can find it in the draft.

You cannot turn track changes off for agent edits. When you mute the agent, its threads leave the gutter and its tracked changes render faintly. They stay in place until you accept or reject them.
