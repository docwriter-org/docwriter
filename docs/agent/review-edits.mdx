## Read a proposal

You will see proposed text in the editor and in a card in the comment gutter. Green text is an addition and red struck text is a removal.

Hover an edit row to flash the matching text. Pin a diff to keep the proposal visible after closing a card. Small edits use a quieter presentation than large edits.

When one comment leads to several edits, the open thread numbers the matching diffs in the document so you can connect each edit to its row.

## Accept or reject

A loose edit is a proposal that is not attached to a comment thread. Use its check button to **Accept** it or its x button to **Reject** it.

**Accept all** accepts every proposal in the current tab. **Reject all** removes every proposal in the current tab, including proposals attached to threads. Neither action affects another tab.

<Frame>
  ![The Accept all and Reject all controls above pending suggestions](/images/agent-accept-reject-all.png)
</Frame>

Thread edits stay grouped under the comment that led to them. You can accept each grouped edit or accept the group.

Thread edits do not have a separate Reject button. Reply to the thread when the agent should revise the proposal. Resolve the thread when you are done with the discussion. Resolving it removes any linked proposals that you did not accept.

An edit becomes stale when you or another edit changes the passage that the proposal was based on. You cannot accept a stale edit because applying the old replacement could overwrite newer text. If the source text changes while you are accepting the edit, you will see the old proposal rejected. The agent will receive a follow up request for a new edit based on the current text. There is no separate Regenerate button.

## Copy proposed text

Use **Copy proposed text** on an edit row. You can also select visible added text in the editor and copy it normally.

## AI provenance

Accepted agent text receives an AI provenance mark so you can find wording that came from an accepted proposal. Use **Highlight AI-written text** to show or hide the marks. Typing your own replacement inside a marked span removes the mark from the text you add.

## Undo

Accept and reject actions use the same undo history as your typing. Press **Command or Control and Z** to undo the latest action, including an accidental accept or reject.

After you accept a paragraph edit, the changed range briefly flashes so you can find it in the draft.

You cannot turn track changes off for agent edits. When you mute proposals, you only hide the proposal layers. Your pending reviews stay in place until you accept or reject them.
