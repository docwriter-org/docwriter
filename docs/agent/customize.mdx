DocWriter has three ways to give the agent guidance that lasts beyond one request.

    Save instructions that should apply across requests.
  </Card>
  <Card title="Writing references" icon="book-open" href="/customize/references">
    Give the agent examples and source material to consult.
  </Card>
  <Card title="Skills" icon="puzzle" href="/customize/skills">
    Add reusable procedures for a specific kind of work.
  </Card>
</CardGroup>

## Choose the right type

- Use a **rule** for a short instruction, such as a required term or citation format.
- Use a **reference** when the agent should learn from an example or consult source material.
- Use a **skill** for a task with a reusable procedure, such as reviewing prose or building a preview.

You can use more than one type in the same project. For example, a rule can require plain headings while a reference shows the voice you want and a skill describes the review process.
