This tour shows where to open files, write text, review changes, and check the agent's work.

## Header

The header contains **Settings** and the provider and model pills. For setup instructions, read [Connect a provider](/connect-provider).

<Frame>
  ![The provider menu open beside the model control](/images/provider-picker.png)
</Frame>

## Rules toolbar

Writing rules appear above the workspace. For instructions on adding and applying rules, read [Writing rules](/customize/rules).

<Frame>
  ![The writing rules panel above the editor](/images/writing-rules-panel.png)
</Frame>

## Sidebar

The left sidebar contains the heading outline and the file tree. Use the outline to move through a long Markdown file. Use the file tree to open and organize workspace files and folders, including `.docwriter`.

Drag the sidebar edge to resize it.

<Frame>
  ![The file tree with file controls and a context menu](/images/file-tree-actions.png)
</Frame>

## Tabs and editor

Tabs appear above the center editor, so you can move between open files without closing your current draft. A tab badge can mark a pending edit, an unresolved agent comment, or a new file created by the agent.

The editor stores plain text. Markdown styling and media previews appear without replacing the source.

<Frame>
  ![Two project files open as tabs above the editor](/images/editor-tabs.png)
</Frame>

## Comment gutter

Pending edits and comment threads appear beside the related text in the comment gutter. The placement helps you review a suggestion in the part of the draft it would change. For an explanation of the review controls, read [Review edits](/agent/review-edits).

<Frame>
  ![A proposed edit in the comment gutter beside the affected text](/images/quickstart-pending-edit.png)
</Frame>

## Agent dock

The agent dock starts as a small pill in the lower right corner. Click the pill to open the dock.

<Frame caption="Click the Agent pill in the lower right corner.">
  ![The collapsed Agent pill highlighted in the lower right corner](/images/agent-dock-opener.png)
</Frame>

The open dock contains **Chat**, the agent's current activity, requests waiting to run, and controls for the current conversation. Check the dock to see whether the agent is working, waiting, or finished. Collapse it when you want more room.

<Frame>
  ![The Chat panel open from the agent dock](/images/chat-popover.png)
</Frame>

For instructions on sending work, read [Send and steer requests](/agent/ask-and-steer). To learn how to pause or cancel the agent and hide proposals, read [Control agent behavior](/agent/agent-behavior).
