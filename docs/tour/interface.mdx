## Header

The header contains the provider and model pills. Use them to change the service or model for the next agent request. **Settings** contains API keys, agent behavior, critique passes, sessions, hooks, skills, appearance, and history detail.

## Rules toolbar

Writing rules appear above the workspace. Add, edit, remove, and apply rules from this toolbar. Agent proposals for new rules or hooks appear as toasts.

## Sidebar

The left sidebar contains the heading outline and the file tree. The outline is a table of contents for the active Markdown file. The file tree contains workspace files and folders, including `.docwriter`.

Drag the sidebar edge to resize it. Use **Settings** to hide the sidebar or file tree.

## Tabs and editor

Tabs appear above the center editor. A tab badge means that the file has pending agent work or an unresolved agent comment.

The editor stores plain text. Markdown styling, tables, images, SVG, and D3 previews appear as visual layers without replacing the source.

## Comment gutter

Pending edits and comment threads appear beside the text in the comment gutter. The gutter contains individual review controls and the **Accept all** and **Reject all** actions.

## Agent dock

The floating dock contains **Chat**, the current activity log, queue status, mute, transcript, and new session controls. Collapse the dock to a small agent pill when you want more room.

Double click the agent pill to pause or resume all agent activity. Click an active pill once to cancel the current run and clear queued messages.
