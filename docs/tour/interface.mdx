## Header

The header contains **Settings** and the provider and model pills. Open [Connect a provider](/connect-provider) to set up the agent.

## Rules toolbar

Writing rules appear above the workspace. Open [Writing rules](/customize/rules) to add or apply one.

## Sidebar

The left sidebar contains the heading outline and the file tree. Use the outline to move through a long Markdown file. Use the file tree to open and organize workspace files and folders, including `.docwriter`.

Drag the sidebar edge to resize it.

## Tabs and editor

Tabs appear above the center editor, so you can move between open files without closing your current draft. A tab badge can mark a pending edit, an unresolved agent comment, or a new file created by the agent.

The editor stores plain text. Markdown styling and media previews appear without replacing the source.

## Comment gutter

Pending edits and comment threads appear beside the related text in the comment gutter. The placement helps you review a suggestion in the part of the draft it would change. Open [Review edits](/agent/review-edits) for the review controls.

## Agent dock

The floating dock contains **Chat**, current activity, requests waiting to run, and controls for the current conversation. Check it to see whether the agent is working, waiting, or finished. Collapse it to a small agent pill when you want more room.

Open [Send and steer requests](/agent/ask-and-steer) to send work. Open [Control agent behavior](/agent/agent-behavior) to pause, cancel, or hide proposals.
