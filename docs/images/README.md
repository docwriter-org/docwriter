Intro hero GIF (requires `ffmpeg` on PATH):

- `intro-flow.gif`. Records a video of typing into a doc, dropping an
  inline directive, and the agent picking it up while typing
  continues. Converted from WebM to GIF via `ffmpeg`. Used as the
  introduction page hero.

To regenerate everything: `npm run docs:screenshots` (one-time setup:
`npx playwright install chromium` and `brew install ffmpeg`).

To regenerate only the Accept-all / pause shots (no agent credential
needed): `node scripts/capture-pause-and-review-all.mjs`.

Env flags:

- `SKIP_AGENT=1`. Skip agent-driven shots (if you don't have Claude
  credentials).
- `SKIP_BLOG=1`. Skip the blog-research scenario.
- `SKIP_LATEX=1`. Skip the LaTeX scenario (if `pdflatex` isn't
  installed).
- `SKIP_GIF=1`. Skip the intro GIF recording.
- `SKIP_STRUCTURAL=1`. Skip the structural shots and the agent-driven
  essay edit (useful when iterating on a single later scenario).
- `AGENT_TIMEOUT_MS=...`. Override the 90s wait for the pending review
  card.
- `KEEP_FIXTURE=1`. Leave the temp fixture on disk for inspection.
