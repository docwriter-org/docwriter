---
title: "Edit an Overleaf project"
description: "Work on an Overleaf repository in DocWriter, build the PDF, and sync accepted changes."
---

Use this workflow when an Overleaf project is available through Git. DocWriter edits the local files. Git moves accepted changes between the local repository and Overleaf.

## Get the project

Connect the Overleaf project to GitHub, or copy its Git URL from the Overleaf project menu. Clone the repository:

```sh
git clone <repository-url> ~/writing/my-paper
cd ~/writing/my-paper
```

Pull before each writing session so the local files include changes made in Overleaf.

## Open the project

Start DocWriter in watch mode:

```sh
docwriter --watch ~/writing/my-paper
```

Open the main TeX file. DocWriter shows the source as plain text and keeps the file available to Git.

<Frame>
  ![A TeX project open in the source editor](/images/overleaf-tex-open.png)
</Frame>

## Build the PDF

Install a TeX distribution that provides `pdflatex`, `bibtex`, and `synctex`.

Open **Settings**, then **Hooks**, and choose the `pdflatex` template. Change the entry file and output when the project does not use `main.tex` and `main.pdf`.

Run the hook once. Fix any missing TeX packages or file names shown in the hook result.

## Open the preview

Open the TeX source and choose the split preview button. DocWriter shows the generated PDF beside the source.

Select source text and choose **Locate in PDF** to find the matching place. Double click the PDF to return to the source line.

SyncTeX navigation requires the build to use `-synctex=1` and produce a `.synctex.gz` file.

<Frame>
  ![The generated PDF beside the LaTeX source](/images/overleaf-pdf-preview.png)
</Frame>

## Ask for an edit

Select a passage or leave an inline directive in a TeX comment:

```tex
% [[ Tighten this paragraph without changing the citations. ]]
```

The comment keeps the TeX file valid while the request waits. Review the proposed source change before accepting it.

<Frame>
  ![A proposed LaTeX edit in the comment gutter](/images/overleaf-pending-edit.png)
</Frame>

Run the build again after accepting the change. Confirm that the PDF compiles and that the output is correct.

## Send the change back

Review the Git diff, then commit and push:

```sh
git status
git diff
git add .
git commit -m "Revise manuscript"
git push
```

DocWriter does not pull or push by default. You can add a Git hook later, but first confirm that manual pull and push work without a credential prompt.

Read [LaTeX and SyncTeX](/automation/latex-and-synctex) for preview details. Read [Hooks](/automation/hooks) before automating the build or Git commands.
