---
title: "Find and appearance"
---

Use the find, outline, and layout controls when a draft becomes hard to move through or the editor feels crowded. The controls change how you view the workspace. They do not change the text in your files.

## Find text

Press **Command or Control and F** to open the document find bar. Type a query, press **Enter** for the next match, and press **Shift and Enter** for the previous match.

Use **Match case** when capitalization should matter. The counter shows the current match and total matches. Press **Escape** to close the bar.

You can search only the active tab.

## Use the outline

You will find the Markdown headings from your active file in the outline. You can use the outline to move to a section in a long draft without searching for its title. Files without Markdown headings have an empty outline.

<Frame caption="The outline appears above the file tree on the left.">
  ![The DocWriter interface with the outline labeled](/images/tour-interface-overview.png)
</Frame>

## Change appearance

Open **Settings** to choose Light, Dark, Solarized Light, Solarized Dark, or Monokai. You can also change the editor font size, wrap long lines, and show line numbers. These settings let you make dense source text easier to read without changing the saved file.

<Frame caption="Theme, font, wrapping, line number, and pane controls are under Settings.">
  ![The Settings menu with the Theme submenu open](/images/appearance-settings.png)
</Frame>

DocWriter uses Lora for prose, Inter for the interface, and Geist Mono for code.

## Resize the workspace

Drag the sidebar edge, the file tree divider, or the split preview divider to resize each region. **Settings**, then **Sidebar** hides the whole left sidebar. **Settings**, then **Files pane** hides only the file tree beneath the outline.

Your text stays within a readable maximum width. You will see the comment gutter beside your text when space allows. At narrower widths, you will see the split preview below the source, and the agent dock collapses to a pill.
