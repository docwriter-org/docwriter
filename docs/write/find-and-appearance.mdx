## Find text

Press **Command or Control and F** to open the document find bar. Type a query, press **Enter** for the next match, and press **Shift and Enter** for the previous match.

Use **Match case** when capitalization should matter. The counter shows the current match and total matches. Press **Escape** to close the bar.

Find searches the active tab only.

## Use the outline

The outline lists Markdown headings from the active file. Click a heading to move to it. Files without Markdown headings have an empty outline.

## Change appearance

Open **Settings** to choose Light, Dark, Solarized Light, Solarized Dark, or Monokai. You can also change the editor font size, wrap long lines, and show line numbers.

DocWriter uses Lora for prose, Inter for the interface, and Geist Mono for code.

## Resize the workspace

Drag the sidebar edge, the file tree divider, or the split preview divider to resize each region. The layout also adapts when the browser window becomes narrow.
