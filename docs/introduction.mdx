DocWriter is a shared writing workspace where you and an AI agent work alongside each other in the same live draft.

DocWriter reimagines AI-assisted writing as ongoing collaboration inside the draft. Keep writing while the agent researches, comments, or proposes changes. Respond beside the text, and the agent can respond as the draft changes.

## What makes DocWriter different

- **Work directly in the draft.** Type an inline instruction, give feedback on selected text, reply to a comment, or keep writing while the agent works elsewhere.
- **Add writing rules and references.** Save rules, examples, reference material, and protected passages so the agent follows your standards rather than a generic prompt.
- **Work across files and the web.** The agent can read and edit workspace files, research on the internet, run shell commands, and handle longer tasks in the background.
- **Review work beside the text.** Comments and proposed changes stay attached to the relevant passage. Accept, reject, or respond without leaving the document.
- **Set agent autonomy.** The agent can wait for direct requests, point out problems, or propose focused edits. Pause, mute, or cancel the agent at any time.
- **Add skills, reviewers, and hooks.** Extend DocWriter with reusable instructions, focused review passes, and shell commands for building PDFs, checking style, or publishing accepted work.
