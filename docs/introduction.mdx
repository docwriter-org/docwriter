You write in the center editor while the agent reads the same live draft. The agent can comment or propose changes, and you decide which changes become part of the file.

## What you can do

- **Add writing rules and references.** Save rules, examples, source material, and protected passages so the agent follows your standards.
- **Work across files and the web.** The agent can read and edit workspace files, search the web, run shell commands, and handle longer tasks in the background.
- **Review work beside the text.** Comments and proposed changes stay attached to the relevant passage. Accept, reject, or respond without leaving the document.
- **Add skills, reviewers, and hooks.** Give the agent reusable instructions, run focused review passes, and run shell commands after an event such as accepting an edit.
