---

DocWriter is useful when you want help with a draft but still want to control every change. You write in the center editor while the agent reads the same live draft. The agent can comment or propose changes, and you decide which changes become part of the file.

You can keep writing while the agent works. You can also set rules for the agent and change how much it may do. DocWriter saves the changes you chose to keep in a plain Markdown file.

## What you can do

- **Save writing rules and source material.** The agent can follow the same instructions and examples on later requests.
- **Work across files and the web.** The agent can read and edit workspace files, search the web, run shell commands, and continue longer tasks in the background.
- **Review work beside the text.** Comments and proposed changes stay attached to the relevant passage, so you can accept, reject, or respond without leaving the document.
- **Set up repeated work.** You can save instructions as skills, add agents that review for a specific concern, and run a shell command after an event such as accepting an edit.
