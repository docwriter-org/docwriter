- **Work in the same live draft, at the same time.**
- **Choose whether the agent waits, comments, proposes changes, or edits directly.**

## Built for writing projects

- **Add writing rules and references.** Save rules, examples, reference material, and protected passages so the agent follows your standards rather than a generic prompt.
- **Work across files and the web.** The agent can read and edit workspace files, research on the internet, run shell commands, and handle longer tasks in the background.
- **Review work beside the text.** Comments and proposed changes stay attached to the relevant passage. Accept, reject, or respond without leaving the document.
- **Add skills, reviewers, and hooks.** Extend DocWriter with reusable instructions, focused review passes, and shell commands for building PDFs, checking style, or publishing accepted work.
