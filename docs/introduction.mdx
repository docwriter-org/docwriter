DocWriter is a shared writing workspace where you and an AI agent work alongside each other in the same live draft.

It reimagines AI-assisted writing as ongoing collaboration inside the draft. Keep writing while the agent researches, comments, or proposes changes. You can respond to its work, and it can respond to yours.

## Work where the writing happens

You do not have to move every request into a separate conversation. Type an instruction inside the draft, select a passage and give feedback, or reply to an agent comment beside the text.

Chat remains available for research and requests that do not belong at one place. The agent can work across the open files in your writing project.

## Keep writing while the agent works

The editor and agent share the same live draft. The agent can keep working while you continue typing, so research and revision tasks do not block your writing.

Agent comments and proposed changes appear beside the relevant text. Accept what helps, reject what does not, or reply with more direction.

## Choose how the agent participates

You decide how proactive the agent should be. It can wait for a direct request, point out a problem, or propose a focused edit.

You can pause the agent, hide proposed changes, cancel a run, or start a new session without changing the draft or your saved writing preferences.
