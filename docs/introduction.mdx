DocWriter is a shared writing workspace where you and an AI agent work alongside each other in the same live draft.

It reimagines AI-assisted writing as ongoing collaboration inside the draft. Keep writing while the agent researches, comments, or proposes changes. You can respond to its work, and it can respond to yours.

## What makes DocWriter different

- **Work directly in the draft.** Type an inline instruction, give feedback on selected text, reply to a comment, or keep writing while the agent works elsewhere.
- **Give the agent your writing context.** Save writing rules, examples, references, and protected passages so the agent works from your standards rather than a generic prompt.
- **Use the tools the work requires.** The agent can read and edit files across the workspace, research on the internet, run shell commands, and handle longer tasks in the background.
- **Review work beside the text.** Comments and proposed changes stay attached to the relevant passage. Accept, reject, or respond without leaving the document.
- **Choose its autonomy.** The agent can wait for direct requests, point out problems, or propose focused edits. Pause, mute, or cancel it at any time.
- **Extend the workflow.** Add skills, custom reviewers, and shell hooks for tasks such as building PDFs, checking style, or publishing accepted work.
