DocWriter is a shared writing workspace where you and an AI agent work alongside each other in the same live draft.

Keep writing while the agent researches, comments, or proposes changes. You can respond to its work, and it can respond to yours.

<Frame>
  ![A writer keeps typing while the agent handles an inline request](/images/intro-flow.gif)
</Frame>

## Work in the document

DocWriter is built around the document rather than a chat transcript. You can type an instruction inside the draft, select a passage and give feedback, or reply to an agent comment beside the text. Chat remains available for requests that do not belong at one place in the document.

The agent reads files in your workspace and can use research, shell, and code tools. Changes to an open document appear in the editor. You can review a proposed edit in the comment gutter before accepting it.

## Keep writing while the agent works

The editor and agent share the same live document. The agent can work while you continue typing, and Yjs combines both streams of changes. Long research and revision tasks do not block the editor.

DocWriter also keeps a live activity log in the floating agent dock. You can open the full transcript when you need more detail.

## Choose how the agent participates

Autonomy is one setting among the other ways you direct the agent. Low autonomy waits for clear requests. Medium autonomy can open a focused comment when it notices a problem. High autonomy can also propose a focused edit.

Agent edits to an existing file are reviewable. You can pause the agent, mute proposed changes, cancel a run, or start a new session without changing your files and saved writing rules.
