---
title: "Recovery"
description: "Fix common problems after a crash, restart, or file change."
---

Start with the section that matches what you see. Most recovery steps do not change your workspace files.

## The editor is blank

The editor stays blank when the browser cannot connect to the document server. Check the terminal where you started DocWriter. If the server stopped, start DocWriter again and reload the browser.

Confirm that you opened a text file. PDF and other binary tabs use a preview instead of the text editor.

If the server is running, look in the terminal for an address or port error. Stop the other DocWriter process, then start this workspace again. Contributors running `npm run dev` should also confirm that ports 5173 and 3001 are available.

## DocWriter keeps stopping

Run DocWriter with `--restart` if you want it to start again automatically after a crash:

```sh
docwriter --restart
```

Reload the browser after the new server starts. The browser reconnects to the new server and loads the latest saved document.

## A proposal is stale

A proposal becomes stale when you change the text that the agent wanted to edit. The Accept button is disabled because the old proposal no longer fits.

Reject the proposal if you no longer need it. To request another version, reply in the related thread or send a new Chat request based on the current text. If an Accept request discovers the mismatch, DocWriter removes the old proposal and asks the agent for a new one automatically.

## A deleted file still appears

Reload DocWriter so it can remove tabs for files that no longer exist. When you delete a file inside DocWriter, DocWriter also deletes its saved editing history.

## You need to reset DocWriter

Delete `.docwriter/docwriter.db` only when you want to clear all DocWriter state for the workspace. Your workspace files remain, but you lose sessions, comments, pending reviews, rules, and interface settings.

Stop DocWriter before deleting the database, then start it again.

Back up the database before deleting it when you may need the old state.

## Old temporary files remain

Choose **New session** to clear `.docwriter/agent/scratch/`. If files remain, make sure the agent is not running before you delete them by hand.
