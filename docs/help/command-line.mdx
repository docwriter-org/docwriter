---

The directory passed to `docwriter` sets the workspace boundary. Confirm it before you create, rename, or delete files in DocWriter.

```text
docwriter [options] [directory]
```

| Option | Meaning |
| --- | --- |
| `-p, --port <n>` | Use this HTTP port. The default is 7723 or another free port. Changing it changes the browser address but does not change saved work. |
| `--host [address]` | Listen on this network address. A bare flag uses 0.0.0.0 and allows other devices on the local network to connect. |
| `--no-open` | Start the server without opening a browser. Saved work is unchanged. |
| `-w, --watch` | Reload the browser after supported files change outside DocWriter. DocWriter replaces only the lines that changed in the file. |
| `--restart` | Start the server again one second after a crash. The active agent run does not resume. |
| `--root <dir>` | Use this directory as the workspace root. The positional directory does the same job. |
| `--new-session` | Clear the saved provider conversation at startup. Workspace files remain. |
| `--api-key <key>` | Set the Anthropic key for this process. The key can appear in shell history or process information. |
| `--model <name>` | Set a fallback model for this process. DocWriter uses it only when the app does not choose a model for a request. |
| `--version` | Print the installed version without starting the server. |

## Common examples

```sh
docwriter ~/writing/book
docwriter --watch ~/writing/paper
docwriter --no-open --port 9000 ~/writing/notes
docwriter --host 0.0.0.0 ~/writing/shared
```

In DocWriter, you select among Claude, OpenAI, Codex, Cursor, and Pi through the provider and model controls. The `--api-key` flag applies only to Claude. The model you choose in the header is sent with each request, so `--model` does not change it.

Use `--host 0.0.0.0` only on a trusted network. Anyone who can reach the server may be able to view workspace data or use configured provider credentials through DocWriter.

Use `--watch` when another program changes workspace files. A reload protects you from continuing with an old browser view. DocWriter replaces only the changed lines and keeps comments, pending reviews, and AI provenance on the other lines. You lose the suggested text of a proposal on a changed line, and you lose your undo history when the browser reloads, so finish or copy that work first.

## Check saved state

Run `docwriter doctor` to check the saved DocWriter state for a workspace. From a checkout, run `npm run doctor --` followed by the same arguments.

```sh
docwriter doctor ~/writing/my-project
```

If you do not give a folder, DocWriter uses `DOCWRITER_ROOT` or the current folder. By default, you get a report and nothing changes. The report has:

- Where the `.docwriter` folder is, and whether another `.docwriter` folder in the current or parent folder might be the one you meant.
- The database schema version and the result of a SQLite integrity check.
- Each saved document, whether its file still exists, and its pending proposals and open comment threads.
- Gaps in the update log numbers, which are expected after deletions and are not damage.
- The number of backups in `.docwriter/backups/`.

Add `--json` to print the report as JSON. Stop DocWriter before you use a repair option; a running DocWriter server does not load the changes until you restart it. DocWriter writes a backup to `.docwriter/backups/` before it applies `--clear-pending`, `--resolve-threads`, or `--gc`. It does not write a backup for `--reopen` or `--compact`, so copy the `.docwriter` folder first if you may need the old state.

| Option | Meaning |
| --- | --- |
| `--reopen <tab>` | Put a closed document back in the tab bar. |
| `--clear-pending` | Reject all pending proposals. |
| `--resolve-threads` | Mark all open comment threads as resolved. |
| `--gc` | Delete closed documents whose file no longer exists. |
| `--compact` | Combine each update log with more than 500 entries into one saved snapshot. With `--tab`, combine that document's log at any size. |
| `--tab <tab>` | Apply `--clear-pending`, `--resolve-threads`, or `--compact` to one document only. |

For `<tab>`, use the file's path relative to the workspace folder, such as `chapters/intro.md`.

## Environment

Useful environment values include `DOCWRITER_ROOT`, `DOCWRITER_DEFAULT_MODEL` (the fallback model that `--model` sets), `DOCWRITER_NEW_SESSION`, `ANTHROPIC_API_KEY`, and provider keys described in [Connect a provider](/connect-provider).

Environment values can override settings loaded from `~/.docwriter/keys.env`. Restart DocWriter after changing an environment value so the new process uses it. Removing a key can stop provider requests. Your earlier transcripts and provider records remain.
