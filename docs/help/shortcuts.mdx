title: "Keyboard shortcuts"
description: "Current shortcuts for the editor, agent, comments, and dialogs."
---

## Editor

| Shortcut | Action |
| --- | --- |
| Command or Control and Enter | Wake the agent now |
| Command or Control and F | Find in the active document |
| Command or Control and / | Comment or uncomment source |
| Command or Control and Z | Undo the latest user action |
| Command or Control, Shift, and Z | Redo |

DocWriter saves continuously. There is no separate Command or Control and S action.

## Chat and comments

| Shortcut | Action |
| --- | --- |
| Command or Control and Enter | Send Chat or a comment reply |
| Enter in Chat | Insert a new line |
| Escape | Close the current popover, menu, or dialog |

## Selected text feedback

| Shortcut | Action |
| --- | --- |
| Enter | Send feedback |
| Shift and Enter | Insert a new line |
| Escape | Close the popup |
| Backspace or Delete in an empty input | Delete the selected document text |

## Find

Enter moves to the next match. Shift and Enter moves to the previous match. Escape closes the find bar.

## Agent dock

Click the idle agent pill to wake it for the active text tab. Double click the pill to pause or resume. Click the active pill once to cancel the current run.

## Tabs and names

Enter saves an inline rename. Escape cancels it or closes a context menu.
