---
title: "Provider errors"
description: "Fix authentication, model, quota, and saved session failures."
---

Start with the message shown in the **Agent auth failed** or **Agent run failed** notice. The full error also remains in the agent activity log.

## The provider says a credential is missing

Open **Settings**, then **API keys**. Check whether the selected provider shows **Key set**, **Using login**, **Missing**, or **Optional**.

Environment variables and project `.env` files take precedence over `~/.docwriter/keys.env`. Restart DocWriter after changing a shell environment variable.

## A command line login expired

Run the provider login command again, then choose **New session** in DocWriter. Claude and Codex can use existing command line logins.

## The selected model does not exist

Open the model pill and choose another model listed for the current provider. A custom model identifier can be saved in the interface even when the provider does not allow the account to use it.

If OpenAI reports that `codex-mini` does not exist, choose an available GPT model. If Claude reports that enabled thinking is not supported, choose another Claude model.

Model access can depend on the account, subscription, region, and API endpoint.

## The provider reached a quota or rate limit

Wait for the limit to reset, or select another provider that has working credentials. Cancel the current run if queued messages should not run after the limit resets.

## A saved session cannot resume

Open **Settings**, then **Sessions**, and choose another session. Start a new session when the saved provider conversation no longer exists.

Switching providers also starts a separate provider conversation. Your workspace files and saved writing settings remain.

## The provider starts but a tool fails

Open the transcript and inspect the failed tool result. Confirm that the file is inside the workspace and that the selected provider supports the requested tool.

Read [Privacy and safety](/help/privacy-and-safety) to understand what a provider can read and which commands can run.
