---
title: "Make your first edit"
description: "Open a file, ask for one change, and review the result."
---

Use this walkthrough to learn how an agent edit moves from a request into your file. You will write a short draft, ask for one change, and decide whether to keep it. At the end, the accepted text will be in the Markdown file on disk.

## Confirm the provider

Check that the provider and model you tested on [Connect a provider](/connect-provider) still appear in the header. If you have not sent a successful request yet, send the test request on that page before continuing.

## Open a draft

Return to the workspace you opened during installation. You can use an existing Markdown file or create a new one for this walkthrough.

## Write something

Choose **New file** in the file tree and name it `draft.md`. Write a heading and a short paragraph about something you are already working on.

You can type directly in the center editor, and DocWriter saves the live draft back to the file.

<Frame>
  ![A new draft open in the DocWriter source editor](/images/quickstart-essay-open.png)
</Frame>

## Ask for one edit

Click **Chat** in the floating agent dock. Send:

```text
Rewrite the opening in fewer words. Make a direct edit while keeping my point and voice.
```

The agent reads the open file and proposes a smaller opening that should keep the same point and tone. You can continue typing while it works.

## Review the suggestion

The changed text appears in the editor, and a review card appears in the comment gutter beside it. Use **Accept** when the proposal says what you mean. Use **Reject** when you want to keep the current text.

<Frame>
  ![A proposed edit in the comment gutter beside the changed text](/images/quickstart-pending-edit.png)
</Frame>

You can accept and reject suggestions independently. A suggestion becomes stale when the text it depends on has changed. Reject a stale suggestion. If an Accept request discovers the mismatch, DocWriter removes the old suggestion and asks the agent for a new one based on the current text.

## Check the file

Open `draft.md` from the workspace folder in any other editor. The accepted text is plain Markdown on disk. Review state and comments remain in `.docwriter/docwriter.db`.
