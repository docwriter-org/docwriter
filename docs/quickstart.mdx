---
title: "Make your first edit"
description: "Open a file, ask for one change, and review the result."
---

The first walkthrough uses an explicit request. Automatic wake, inline directives, and autonomy can wait until the basic review loop works.

## Open a blank workspace

```sh
docwriter --new-session ~/writing/docwriter-quickstart
```

DocWriter creates the folder when it does not exist. The file tree starts empty.

## Write something

Click **New file** and name it `draft.md`. Write a heading and a short paragraph about something you are already working on.

You can type directly in the center editor, and DocWriter saves the live draft back to the file.

<Frame>
  ![A new draft open in the DocWriter source editor](/images/quickstart-essay-open.png)
</Frame>

## Ask for one edit

Click **Chat** in the floating agent dock. Send:

```text
Rewrite the opening in fewer words. Make a direct edit while keeping my point and voice.
```

The agent can read the open file and propose a change. You can continue typing while it works.

## Review the suggestion

The changed text appears in the editor, and a review card appears in the comment gutter beside it. Use **Accept** to keep the proposed text or **Reject** to remove the proposal.

<Frame>
  ![A proposed edit in the comment gutter beside the changed text](/images/quickstart-pending-edit.png)
</Frame>

You can accept and reject suggestions independently. A suggestion becomes stale when the text it depends on has changed, and DocWriter asks the agent to regenerate it against the current draft.

## Check the file

Open `draft.md` from the workspace folder in any other editor. The accepted text is plain Markdown on disk. Review state and comments remain in `.docwriter/docwriter.db`.
