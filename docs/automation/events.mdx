## Events

* **PreToolUse** runs before a tool. A failing command can block the tool.
* **PostToolUse** runs after a successful tool.
* **PostToolUseFailure** runs after a failed tool.
* **UserPromptSubmit** runs when the user submits a request.
* **Stop** runs when the main agent turn ends.
* **SubagentStop** runs when a subagent ends.
* **SessionStart** and **SessionEnd** run at session boundaries.
* **Notification** runs for agent notifications.

## Matchers

The matcher is a case insensitive regular expression tested against the tool name. Leave it empty to match every tool for that event.

Tool names can differ across providers. Check the live activity log before writing a narrow matcher.

## Variables

Use these values inside a command or output path:

* `{{file}}` is the workspace relative file used by the tool.
* `{{stem}}` is the file path without its final extension.
* `{{tool}}` is the tool name.

File values are empty for events that do not belong to a file tool.
