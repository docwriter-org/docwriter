## Events

Choose an event based on the action that should start the command. An event is a named point in the agent's work, such as the start of a tool call or the end of a turn.

* **PreToolUse** runs before a tool. Use it to inspect or report work before the tool continues. A failing command is reported but does not block the tool.
* **PostToolUse** runs after a successful tool. Use it to build or check a file after the agent changes it.
* **PostToolUseFailure** runs after a failed tool. Use it to record or report tool failures.
* **UserPromptSubmit** runs when you submit a request. Use it for setup that every request needs.
* **Stop** runs when the main agent turn ends. Use it for work that should happen once after the agent finishes, such as building a whole project.
* **SubagentStop** runs when a subagent ends. A subagent is a separate agent that handles part of a task.
* **SessionStart** and **SessionEnd** run when a DocWriter agent session starts or ends. Use them for session setup and cleanup.
* **Notification** runs when the agent sends a notification. Use it when an outside command should react to those notices.

Claude supports every event in this list. Other providers currently support **PostToolUse**, **PostToolUseFailure**, and **Stop** hooks.

## Matchers

A matcher limits a hook to selected tool names. DocWriter treats the matcher as a case insensitive regular expression, which is a text pattern. For example, `Edit|Write` matches a tool name that contains `Edit` or `Write`.

Leave the matcher empty to run the hook for every tool that reaches the chosen event. Tool names can differ across providers, so check the live activity log before you use a narrow matcher.

## Variables

Variables let one hook use the file and tool that caused the event. Add the following values to a command or output path:

* `{{file}}` is the workspace relative file used by the tool.
* `{{stem}}` is the file path without the final extension.
* `{{tool}}` is the tool name.

For example, if a tool edits `notes/draft.md`, then `{{file}}` becomes `notes/draft.md` and `{{stem}}` becomes `notes/draft`. DocWriter removes only the final extension, so `notes/draft.first.md` becomes `notes/draft.first`.

File values are empty when the event does not belong to a file tool. After you use **Run now** or trigger the event, inspect the command in the live agent dock. The displayed command shows the values that DocWriter substituted, and its status shows whether it finished successfully.
