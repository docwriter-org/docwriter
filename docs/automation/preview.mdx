title: "Generated previews"
description: "Open generated files and reload them when a hook completes."
---

## Match an output

DocWriter first looks for a same name PDF beside an active TeX file. If none exists, it resolves the output template from the first enabled matching hook.

Set a hook output such as `{{stem}}.html`, `{{stem}}.pdf`, or `{{stem}}.svg`.

## Open a preview

**Preview window** opens a separate browser window. The split preview button opens the output beside the source and lets you resize both panes.

Supported output includes PDF, HTML, SVG, common image formats, Markdown, and plain text. Use **Raw** to open the generated file in a normal browser window.

## Live reload

After a successful hook with an output, DocWriter sends a preview update. The preview reloads while preserving PDF page and scale, document scroll, or image scroll when possible.

The preview shows its connection state and the time of the latest update.
