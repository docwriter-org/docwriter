title: "Hooks"
description: "Run workspace shell commands when agent events occur."
---

Hooks run shell commands from the workspace root. They have the same access as your shell, so review every command before enabling it.

## Create a hook

Open **Settings**, then **Hooks**. Start from a template or add your own event, matcher, command, and optional output.

Current templates cover pdflatex, Pandoc HTML, Pandoc PDF, Mermaid, and two Git commit and push variants.

## Manage hooks

Use the checkbox to enable or disable a hook. Use **Run now** to test it. Remove a hook with the x control.

The agent can propose a hook through a **Proposed hook** toast, including its preview output path. Accepting the toast saves and enables the hook; use its checkbox in Settings to disable it.

## Preview output

Set **Output** when the command produces a file that DocWriter can preview. The Preview controls use the first enabled hook whose resolved output exists for the active source file.

The pdflatex template runs at **Stop**, after an agent turn. It does not run after every user keystroke.

## Failures

The live agent dock shows a hook as running, done, or failed. DocWriter records the exit code and clips long standard output and error streams.

A failing **PreToolUse** hook can block the tool. Other failures are reported without reversing work that already completed.
