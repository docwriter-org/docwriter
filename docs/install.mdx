## Requirements

DocWriter supports macOS and Linux. Windows users can run it through WSL.

The repository pins Node.js 22.22.2. Run `node --version` before installing, and use `nvm use` from the repository when another Node version is active.

## Install from source

```sh
git clone https://github.com/docwriter-org/docwriter.git
cd docwriter
nvm use
npm install
npm run build
npm link
```

Check the installed command:

```sh
docwriter --version
```

## Open a workspace

Pass the folder that contains your writing project:

```sh
docwriter ~/writing/my-project
```

DocWriter opens a browser and binds to `127.0.0.1` by default. The folder becomes the workspace boundary for files, previews, hooks, and agent tools.

## Update an existing installation

```sh
git pull origin main
nvm use
npm install
npm run build
npm link
```

Back up the project files and `.docwriter/docwriter.db` before an update when the workspace contains important session or review history.
