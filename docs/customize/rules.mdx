---
title: "Writing rules"
description: "Tell the agent what it should always preserve or avoid."
---

Use a writing rule when an instruction should apply across requests. A rule is useful for choices such as tone, terminology, citation format, or text that the agent must not change.

## Add a rule

Open the rules toolbar above the workspace and choose **Add rule**. Write one clear instruction that the agent can check against the draft.

For example:

```text
Use complete sentences. Do not use sentence fragments for emphasis.
```

Add an example violation when the rule could be interpreted in more than one way. You can edit or remove a rule from the same toolbar.

Saving a rule wakes the agent so it can check the open files. When several tabs are open, DocWriter asks which tabs the rule should apply to.

## Check a draft against the rules

Choose **Apply rules to document** in the rules toolbar. Select the active tab, every open tab, or a set of tabs.

The agent reads the selected text and proposes changes where the draft breaks a rule. Review each proposal before accepting it.

## Review a proposed rule

The agent can suggest a rule after it notices a repeated preference. A **Proposed rule** message appears above the workspace. Accept it to save the rule, or dismiss it when the instruction should apply only to the current request.

## Protect exact text

Select a passage and choose **Freeze for agent** when the words must remain unchanged. DocWriter saves a rule for that exact text and shows a lock beside the passage.

Click the lock and choose **Unlock, allow agent to edit** when the text can change again.

## Choose between a rule and a reference

Use a rule for an instruction the agent can follow, such as "Use sentence case for headings." Use a [writing reference](/customize/references) when the agent should learn from an example, such as an earlier article in your voice.
