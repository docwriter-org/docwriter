---
title: "Intended audience"
---

Use an intended audience when you want the agent to write for a specific reader. You describe who the draft is for, so later edits can match that reader's background and how much explanation they need.

## Set the audience

Open **Settings**, then **Intended audience**. Write who you are writing for in your own words.

For example:

```text
Busy engineering managers who already know Kubernetes; skip basics, keep examples concrete and short.
```

Choose **Save** when the description is ready. Choose **Clear** when you no longer want a specific reader.

<Frame>
  ![The Intended audience panel open from Settings](/images/intended-audience-panel.png)
</Frame>

When you save or clear the audience, the agent wakes and uses the new description on later requests.

## Choose between an audience, a rule, and a reference

- Use an **intended audience** when you want to name the reader, such as "first-year biology students."
- Use a [writing rule](/customize/rules) when you want a checkable instruction, such as "Use sentence case for headings."
- Use a [writing reference](/customize/references) when you want the agent to learn from an example of your voice or to consult source material.
