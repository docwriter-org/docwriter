---
title: "Writing references"
---

Use a writing reference when the agent needs an example or source to complete a request. A published article can show the voice you want, while a source file or URL can provide facts and preferred terms for a project.

## Add a reference

Open **Settings**, then **Writing references**. Add a reference in one of these ways:

- Use the current file.
- Paste a writing sample.
- Save a URL.

Give the reference a name that explains why the agent should use it. For example, name a sample "Published posts in my voice" instead of "Sample 1."

<Frame>
  ![Writing references in Settings](/images/writing-references-panel.png)
</Frame>

## Control when a reference is available

Enable a reference when the agent may use it in new requests. Disable it when the source is unrelated to your current work and you want to keep it saved for later. Removing a reference does not change the original file or URL.

When you add a reference, the agent wakes and considers the new material during the next pass. The saved name helps you tell the agent which reference matters for a later request.

## Tell the agent what to use

Name the reference in your request when one source is especially important:

```text
Revise the opening to match the tone of "Published posts in my voice."
```

After you send the request, the agent can consult the named material while it works and propose edits based on it. A reference supplies material for the request. Use a [writing rule](/customize/rules) when the same instruction should apply to later requests.
