title: "Writing references"
description: "Voice samples the agent matches when it generates prose."
---

A **writing reference** is a sample of prose whose voice you want the
agent to match. References complement [writing
rules](/customize/rules): rules are explicit instructions ("avoid
passive voice"); references are implicit ("write like this").

## Adding a reference

In the menu bar, open **Settings** and click **Writing references**.

<Frame>
  ![The writing references panel open under Settings](/images/writing-references-panel.png)
</Frame>

Three ways to add a reference:

- **Use the current file.** Saves the active tab's content as a
  reference.
- **Paste a sample.** Paste a chunk of prose directly into the panel.
- **Save a URL.** Point at a web page; DocWriter fetches the text.

Each reference can be enabled or disabled. Disabled references stay in
the panel but aren't sent to the agent.

## Examples

- A previous blog post of yours, for the agent to match in a new one.
- A paper introduction whose tone you want to emulate.
- A style guide page (e.g., a journal's prose conventions) for academic
  writing.
- A specific author's writing whose voice fits the project.

## How references compare to rules

| Use a rule when                                | Use a reference when                                |
| ---------------------------------------------- | --------------------------------------------------- |
| You can articulate the preference as a sentence | The preference is mostly about tone and rhythm     |
| It applies to every piece of writing            | It applies to a specific project or genre          |
| It's a hard constraint (avoid X, always do Y)   | It's a soft pull toward a particular voice         |

Both can be active at the same time. Rules tell the agent what not to
do; references show it what good output looks like.
