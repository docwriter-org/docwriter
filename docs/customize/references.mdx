---
title: "Writing references"
description: "Give the agent examples and source material to consult."
---

Use a writing reference when the agent needs an example or source, rather than an instruction. A reference can show your voice, define preferred terminology, or provide facts for a project.

## Add a reference

Open **Settings**, then **Writing references**. Add a reference in one of these ways:

- Use the current file.
- Paste a writing sample.
- Save a URL.

Give the reference a name that explains why the agent should use it. For example, name a sample "Published posts in my voice" instead of "Sample 1."

<Frame>
  ![Writing references in Settings](/images/writing-references-panel.png)
</Frame>

## Control when a reference is available

Enable a reference when the agent may use it. Disable it when you want to keep the saved material without including it in new requests. Removing a reference does not change the original file or URL.

Adding a reference wakes the agent so it can consider the new material during the next pass.

## Tell the agent what to use

Name the reference in your request when one source is especially important:

```text
Revise the opening to match the tone of "Published posts in my voice."
```

References provide material to consult. They do not create a permanent instruction. Use a [writing rule](/customize/rules) when the same instruction should apply to later requests.
