# Writing Style Reference

When rendering atoms into prose, read the reference files in the `examples/` directory to understand the user's preferred writing style. Match:

- Sentence length and rhythm
- Vocabulary level and tone
- Use of examples and transitions
- Voice (active/passive preference)
- Level of formality

Apply these style patterns when writing new prose or rewriting existing sentences.
